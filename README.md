# Focus Timer

A browser-based focus timer for running work blocks and tracking completed focus sessions for the current day.

## Current scope

The approved MVP will let a user choose a 10, 20, or 30 minute work duration, run the timer, pause or reset the session, and count completed focus blocks for a selected day. Persistence will stay client-side for now, behind a small storage adapter.

## Quick start

```bash
npm install
npm run dev
```

## Validation

```bash
npm test
npm run build
```
